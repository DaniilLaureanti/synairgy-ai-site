# Architecture decisions

Create a new numbered file for significant choices. Never renumber accepted ADRs.
Use: title, status/date, context, alternatives, decision, consequences, verification.
An updated direction gets a new ADR with a `Supersedes: 000N` link. Link the ADR
from the relevant checkpoint and architecture document. Routine implementation
details do not need an ADR.
